# 총무 안내 데스크 (부서 포털)

근무 환경·안전 안내 포털입니다. 별도 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 폴더 구성

```
부서포털/
├─ index.html      포털 본체 (현재 버전)
├─ README.md       사용법 (이 문서)
├─ files/          자료실 파일 (PDF 등)
│  ├─ emergency-response-guide.pdf
│  └─ facility-guide.pdf
└─ 이전버전/        이전 버전 보관
   └─ dept-portal-v2.html
```

## 사용법

1. `index.html`을 더블클릭해 브라우저(Chrome·Edge)에서 엽니다.
2. 상단 메뉴로 항목 이동: 시설 안내 · 신청 절차 · 비상 대응 · 출장 경비 계산기 · 총무 FAQ · 자료실
3. **신청 절차**: 사무용품·명함·시설 수리·차량 탭을 누르면 단계별 절차가 표시됩니다.
4. **비상 대응**: 화재·지진·정전·응급환자 버튼을 누르면 행동 요령이 표시됩니다. 119·112는 눌러서 바로 전화할 수 있습니다.
5. **출장 경비 계산기**: 이동 거리(km), 연비(km/L), 유류비 단가(원/L)를 입력하면 예상 유류비가 계산됩니다. 왕복 체크 시 거리가 2배로 계산되며, 통행료·주차비는 포함되지 않습니다.
6. **총무 FAQ**: 검색창에 키워드(예: 주차, 명함, 회의실)를 입력하면 질문이 필터링됩니다.
7. **자료실**: 파일명·설명·용량이 표시되며, 다운로드 버튼을 누르면 한글 파일명으로 바로 저장됩니다.

## 수정 방법 (담당자용)

- **문구·내선번호**: `index.html`에서 `내선 ○○○○`, 층별 안내, FAQ는 예시 문구이므로 실제 내용으로 바꿉니다.
- **자료실 파일 추가**: 파일을 `files/` 폴더에 넣고, `index.html` 자료실의 카드 하나를 복사해 제목·설명·용량·경로를 바꿉니다.
  - 예: `<a class="btn" href="files/facility-guide.pdf" download="사옥 시설 이용 안내서.pdf">`
  - `href`는 `files/영문파일명`, `download`는 저장될 한글 파일명(확장자 포함)입니다.
- **파일명 규칙**: 한글·공백 없이 영문 소문자와 하이픈만 사용합니다. (예: `office-supply-request.docx`)
- **색상**: `index.html` 상단 `:root`의 CSS 변수에서 한 번에 바꿀 수 있습니다.
- **버전 관리**: 큰 수정 전에 현재 `index.html`을 `이전버전/` 폴더에 복사해 둡니다.

## 배포

`index.html`과 `files/` 폴더를 함께 사내 웹서버(또는 공유 폴더)에 올립니다. 상대경로(`files/...`)를 쓰므로 두 항목의 위치 관계를 유지해야 합니다.
